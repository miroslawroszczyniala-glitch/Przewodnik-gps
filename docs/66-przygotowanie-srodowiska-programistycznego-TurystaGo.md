# 66. Przygotowanie środowiska programistycznego TurystaGo

## 1. Cel

Przygotowanie środowiska niezbędnego do rozpoczęcia tworzenia i testowania aplikacji TurystaGo.

## 2. Komputer

Do tworzenia aplikacji potrzebny będzie komputer umożliwiający instalację narzędzi programistycznych oraz uruchamianie emulatora lub podłączenie telefonu.

## 3. System operacyjny

Środowisko powinno być przygotowane w sposób umożliwiający tworzenie i testowanie aplikacji na Androida, a w przyszłości również na iOS.

## 4. Środowisko programistyczne

Należy zainstalować odpowiednie środowisko programistyczne oraz narzędzia wymagane przez wybraną technologię.

## 5. Flutter

Jeżeli po wykonaniu testów zostanie wybrany Flutter, należy zainstalować Flutter SDK oraz wymagane komponenty.

## 6. Android Studio

Android Studio może zostać wykorzystane do instalacji Android SDK, zarządzania urządzeniami testowymi oraz uruchamiania emulatora Androida.

## 7. Git i GitHub

Projekt będzie przechowywany w repozytorium GitHub TurystaGo-app. Git będzie służył do zapisywania zmian oraz tworzenia kolejnych wersji projektu.

## 8. Struktura projektu

Po przygotowaniu środowiska zostanie utworzona właściwa struktura katalogów i plików aplikacji zgodnie z punktem 63 dokumentacji.

## 9. Testowanie na telefonie

W miarę możliwości aplikacja będzie testowana również na rzeczywistym telefonie z systemem Android.

## 10. Emulator

Emulator Androida może służyć do sprawdzania działania aplikacji bez konieczności ciągłego korzystania z fizycznego telefonu.

## 11. Test GPS

Jednym z pierwszych testów będzie sprawdzenie możliwości wykorzystania lokalizacji GPS przez aplikację.

## 12. Test mapy

Po uruchomieniu podstawowego projektu należy sprawdzić możliwość wyświetlenia mapy oraz aktualnej pozycji użytkownika.

## 13. Test interfejsu

Należy sprawdzić wygląd pierwszego ekranu, wielkość przycisków, czytelność tekstu oraz wygodę obsługi na telefonie.

## 14. Kontrola wersji

Każda ważniejsza zmiana w projekcie powinna być zapisywana w GitHubie, aby można było wrócić do wcześniejszej wersji.

## 15. Kopie bezpieczeństwa

Repozytorium GitHub będzie pełniło również funkcję dodatkowego zabezpieczenia kodu i dokumentacji projektu.

## 16. Etap testowy

Przed rozpoczęciem tworzenia pełnej aplikacji należy uruchomić prosty projekt testowy i sprawdzić, czy całe środowisko działa prawidłowo.

## 17. Przygotowanie do programowania

Dopiero po prawidłowym przygotowaniu środowiska można rozpocząć tworzenie pierwszych elementów właściwej aplikacji TurystaGo.

## Cel modułu

Przygotowanie kompletnego środowiska programistycznego umożliwiającego rozpoczęcie rzeczywistego tworzenia, uruchamiania i testowania aplikacji TurystaGo.
